# HypoXPy
A modulated comprehensive *Python* interface for hypocenter location codes

![plot1](/figs/HypoXPy_logo.png)

This package doesn't intend to be a detailed documentation of each earthquake location method and code. Instead, we focus on providing a streamlined, user-friendly, and modulated interface for a collection of computer codes for earthquake location or relocation. The ultimate goal is to make this package a one-stop shop with a comprehensive collection of methods.

The logic of this package is heavily inspired by, and modified and simplified from Hypo-Interface-Py (https://github.com/YijianZhou/Hypo-Interface-Py). We acknowledge the developers of Hypo-Interface-Py.
