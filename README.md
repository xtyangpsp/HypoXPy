# HypoXPy
A comprehensive modulized Python interface for hypocenter location codes

![plot1](/figs/HypoXPy_logo.png)

This package doesn't intend to be a detailed documentation of each earthquake location method and code. Instead, we focus on providing a streamlined, user-friendly, and modulized interface for a collection of computer codes for earthquake location or relocation. The ultimate goal is to make this package a one-stop shop with a comprehensive collection of methods.
